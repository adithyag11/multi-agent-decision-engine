Formula Bench · Multi-Agent Decision Engine

The three calculators the Financial Analyst agent is allowed to use

Everything here is ordinary, deterministic arithmetic — the Beneish M-Score, Altman Z''-Score, and ESG composite functions from tools/formulas.py, ported line-for-line. No model call happens between an input changing and a score updating below.

Scope. This is the scoring core only. The full engine also has a Data Engineer agent fetching these figures from records, a Risk/Critic agent with independent hard-gate checks that can escalate or reject a result, real API-key authorization, a durable job queue, and a hash-chained audit ledger — none of that machinery runs on this page.

Each panel below also reads a data file, if you'd rather import figures than type them — JSON, or CSV as field,value rows or one header row plus one data row. Column names are matched loosely (a column called "Total Revenue" is understood as revenue).
